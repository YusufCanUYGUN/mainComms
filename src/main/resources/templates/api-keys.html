How to Use API Keys

Include your API key in the X-API-Key header when making requests to the API:

X-API-Key: your-api-key-here

API Endpoints:

  • GET /portakalapi/opencomputers/reactormenagementV1/reactors - List reactors
  • POST /portakalapi/opencomputers/reactormenagementV1/reactors - Register reactor
  • PUT /portakalapi/opencomputers/reactormenagementV1/reactors/{id} - Update reactor
  • GET /portakalapi/opencomputers/batterymanagement/status - Get battery status
  • PUT /portakalapi/opencomputers/batterymanagement/status/{id} - Update battery
